# E-Commerce-sales-dashboard
E-Commerce Sales Dashboard:
  A Power BI dashboard built to analyze and visualize e-commerce sales performance using basic Power BI features — no DAX formulas used.

Project Overview:
  This dashboard provides insights into overall sales and regional trends.

It is built entirely with:
  Power Query for data cleaning,
  Default Power BI visuals,
  Slicers and filters,
  Basic formatting,
  No advanced calculations or DAX measures are included.

Dashboard Highlights:
  The dashboard includes the following insights:
    Total Sales,
    Sales by Category and Sub-Category,
    Sales by Region / State.

Tools Used:
  Power BI Desktop,
  Power Query Editor,
  Excel dataset.
